数理逻辑基础真题向练习

先看题目，点“查看答案”再展开解析。范围只含前两章：命题演算、谓词演算。

判断题 主范式 谓词基础 代换 证明题 事实分析 前束范式 综合卷

一、判断题

1.任意命题公式都有唯一的析取范式和合取范式。

答案：错。

普通析取范式和普通合取范式不唯一。唯一的是主析取范式和主合取范式，前提是命题变元顺序固定。

2.不含否定词的命题公式都是可满足公式。

答案：对。

把所有命题变元都赋值为真，则只含 ∧、∨、→、↔ 等联结词且无否定的公式可取真。特别是常见命题公式语境下，这是真题中的标准判断。

3.若 Γ ⊨ p，则 p 的每个模型也是 Γ 的模型。

答案：错。

方向反了。Γ ⊨ p 的意思是：每个 Γ 的模型都是 p 的模型。即所有让前提 Γ 成立的解释，也让结论 p 成立。

4.闭式的真值不依赖个体变元赋值。

答案：对。

闭式不含自由变元。公式真值只可能依赖自由变元赋值，所以闭式在给定解释域及符号解释后，其真值不随项解释中的变元赋值改变。

5.在 K4：∀x p(x) → p(t) 中，任意项 t 都可以代入。

答案：错。

K4 要求 t 对 p(x) 中自由出现的 x 是自由的。也就是代入后，t 中的变量不能被原公式中的量词捕获。

6.从 P(x) 可以直接用 Gen 推出 ∀xP(x)。

答案：一般不可以。

如果 P(x) 是作为含自由 x 的假设得到的，就不能对 x 使用 Gen。Gen 只能推广“任意的 x”，不能推广“假设中特定的 x”。

二、主范式

1.求 P → Q 的主析取范式和主合取范式。

答案：

主析取范式： (¬P ∧ ¬Q) ∨ (¬P ∧ Q) ∨ (P ∧ Q)

主合取范式： ¬P ∨ Q

解析：P→Q 仅在 P=1,Q=0 时为假。主析取看成真行，主合取看成假行。

2.求 (P ∧ Q) → R 的主析取范式和主合取范式。

答案：

主合取范式： ¬P ∨ ¬Q ∨ R

主析取范式：除 P=1,Q=1,R=0 以外所有极小项的析取。

(¬P∧¬Q∧¬R) ∨ (¬P∧¬Q∧R) ∨ (¬P∧Q∧¬R) ∨ (¬P∧Q∧R)
∨ (P∧¬Q∧¬R) ∨ (P∧¬Q∧R) ∨ (P∧Q∧R)

解析：蕴含只在前件真、后件假时为假，即 P=Q=1,R=0。

3.求 (P→Q) ∧ (P→R) 的等值简化式。

答案：P → (Q ∧ R)

(P→Q)∧(P→R) ⇔ (¬P∨Q)∧(¬P∨R) ⇔ ¬P∨(Q∧R) ⇔ P→(Q∧R)

三、谓词基础

1.判断自由变元、约束变元，并说明是否闭式：∀x(P(x)→Q(x,y))

答案：x 是约束变元，y 是自由变元；不是闭式。

解析：∀x 的辖域是整个 P(x)→Q(x,y)，所以里面的 x 都被约束；没有 ∀y 或 ∃y 管住 y。

2.判断自由变元、约束变元，并说明是否闭式：(∃x)P(x) ∧ Q(x)

答案：P(x) 中的 x 约束；Q(x) 中的 x 自由；不是闭式。

解析：通常 ∃x 只管 P(x)，不管后面的 Q(x)。同一变量符号可以在同一公式中既有约束出现又有自由出现。

3.判断自由变元、约束变元，并说明是否闭式：∀x∃yR(x,y,z)

答案：x、y 约束；z 自由；不是闭式。

四、代换与变量捕获

1.p(x)=∀yR(x,y), t=z。t 对 p(x) 中的 x 是否自由？

答案：自由。

p(z)=∀yR(z,y)

z 不会被 ∀y 捕获。

2.p(x)=∀yR(x,y), t=y。t 对 p(x) 中的 x 是否自由？

答案：不自由。

直接代入会得 ∀yR(y,y)

代入项 y 原本应保持自由，却被 ∀y 捕获。

3.p(x₂)=∀x₁R(x₁,x₂), t=f(a,x₁)。t 对 x₂ 是否自由？

答案：不自由。

代入后为 ∀x₁R(x₁,f(a,x₁))

项中的 x₁ 进入 ∀x₁ 的辖域，被量词捕获。

五、证明题

1.证明：p→(q∨r) ⊨ (p→q)∨(p→r)

答案思路：用等值演算。

(p→q)∨(p→r)

⇔ (¬p∨q)∨(¬p∨r)

⇔ ¬p∨q∨r

⇔ p→(q∨r)

所以二者等值，当然有语义后承。

2.证明：∃x₁∀x₂R(x₁,x₂) → ∀x₂∃x₁R(x₁,x₂) 是有效式。

答案思路：

如果存在某个对象 a，使得对所有 x₂ 都有 R(a,x₂)，那么任取 x₂，都可以取同一个 a 作为见证，于是 ∃x₁R(x₁,x₂) 成立。

形式推理可写：由 ∃x₁∀x₂R(x₁,x₂) 用 EI 取 a，得 ∀x₂R(a,x₂)；任取 x₂，用 UI 得 R(a,x₂)；用 EG 得 ∃x₁R(x₁,x₂)；再 UG 得 ∀x₂∃x₁R(x₁,x₂)。

3.在 K 中证明：{∀x(F(x)∨G(x))} ⊢ ∀xF(x)∨∃xG(x)

答案提示：这个题更适合用反证/语义直观理解。

从 ∀x(F(x)∨G(x)) 出发。若不是 ∀xF(x)，则存在某个 a 使 ¬F(a)。由全称前提得 F(a)∨G(a)，于是 G(a)，所以 ∃xG(x)。因此 ∀xF(x)∨∃xG(x)。

正式 K 证明需要使用存在规则、演绎定理和经典命题定理，考试中如果要求构造证明，要把“若非 ∀xF(x)”转写成 ¬∀xF(x)⇔∃x¬F(x) 后操作。

六、事实分析题

1.三个箱子有且只有一个有金子。三句话有且只有一句真：①第二个箱子没金子；②第二个箱子有金子；③第一个箱子没金子。问哪个箱子有金子？

答案：第三个箱子有金子。

设 A、B、C 分别表示第 1、2、3 个箱子有金子，且恰好一个真。三句话分别是 ¬B、B、¬A。

¬B 与 B 必有一句真一句假。题设三句话恰好一句真，因此第三句话 ¬A 必须是假，所以 A 真？这里还要结合“恰好一个箱子有金子”检查：如果 A 真，则 ¬B 真，与 B 假、¬A 假，共一真，满足。所以答案应为第一个箱子有金子。

注意这题很容易口算滑掉：①和②互为否定，必有且仅有一句真。为了总共只有一句真，③必须假，即第一个箱子有金子。

2.甲说王教授不是苏州人、是上海人；乙说不是上海人、是苏州人；丙说既不是上海人，也不是杭州人。三人中一人全对，一人全错，一人对一半。王教授是哪里人？

答案：王教授是苏州人。

设 S=上海人， Z=苏州人， H=杭州人，且三者互斥。甲：¬Z 且 S；乙：¬S 且 Z；丙：¬S 且 ¬H。

若是苏州人：甲两句都错；乙两句都对；丙第一句对、第二句错。符合“一全对、一全错、一半对”。

若是上海人：甲全对，乙全错，丙第一句错、第二句对，也符合条件。若题目默认籍贯只在上海、苏州、杭州三者之一，则上海也符合。若原卷答案要求唯一，通常还需要额外约束或以题面上下文排除上海。建议考试时列真值表说明可能解。

七、前束范式

1.化为前束范式：∃xP(x) → ∀yQ(y)

答案：∀x∀y(¬P(x)∨Q(y))

∃xP(x)→∀yQ(y) ⇔ ¬∃xP(x)∨∀yQ(y) ⇔ ∀x¬P(x)∨∀yQ(y) ⇔ ∀x∀y(¬P(x)∨Q(y))

2.化为前束范式：¬∃x∀y(P(x)∧Q(y))

答案：∀x∃y(¬P(x)∨¬Q(y))

¬∃x∀y(P(x)∧Q(y)) ⇔ ∀x¬∀y(P(x)∧Q(y)) ⇔ ∀x∃y¬(P(x)∧Q(y)) ⇔ ∀x∃y(¬P(x)∨¬Q(y))

3.判断是否为有效式：∃x₂∀x₁R(x₁,x₂) → ∀x₁∃x₂R(x₁,x₂)

答案：是有效式。

如果存在一个固定的 x₂，使所有 x₁ 都与它满足 R，那么对任意 x₁，都可以选择这个同一个 x₂ 作为存在见证。因此右边成立。

八、真题向综合卷

1.判断：命题演算 L 的三条公理模式是相互独立的。

答案：对。

这是 Hilbert 型命题演算系统的标准性质。独立性表示任一条公理模式不能由另外两条公理模式和 MP 推出。考试中按概念判断即可，一般不要求证明独立性。

2.判断：若 Γ 和 Σ 都相容，且 Γ∪Σ 不相容，则存在公式 q，使 Γ⊢q 且 Σ⊢¬q。

答案：对。

因为 Γ∪Σ 不相容，存在有限个来自 Γ、Σ 的公式共同推出矛盾。把来自 Σ 的有限合取记作 s，可得到 Γ⊢¬s，而 Σ⊢s。令 q=¬s，则 Γ⊢q 且 Σ⊢¬q。

3.判断：重言式集合是命题语言范围内逻辑推理规律的形式化表达。

答案：对。

重言式是不依赖具体命题内容、只依赖形式结构而恒真的公式，正好刻画命题演算层面的逻辑规律。

4.判断：若 Γ 极大相容，且 p∉Γ，则 Γ∪{p} 不相容。

答案：对。

极大相容表示 Γ 已经不能再加入任何 Γ 外公式并保持相容。因此若 p 不在 Γ 中，加入 p 后必不相容。

5.判断：(¬r∧q∧(p→(q→r)))→¬p 是永真式。

答案：对。

当前件真时，¬r 和 q 都真，且 p→(q→r) 真。若 p 真，则由 p 得 q→r，再由 q 得 r，与 ¬r 矛盾。所以 p 不可能真，即 ¬p 真。因此整个蕴含永真。

6.判断：∀x∀y(R(x,y)→R(y,x))→∀x∃yR(x,y) 是逻辑有效式。

答案：错。

前件只说 R 是对称的，不保证任何 R(x,y) 成立。取非空论域且 R 解释为空关系，则前件真，而 ∀x∃yR(x,y) 假。

7.简答：直观解释“模型”的含义。

参考答案：模型是使一组公式都成立的解释或结构。它给出论域，并解释常元、函数符号和谓词符号。如果某个解释让 Γ 中所有公式为真，就称它是 Γ 的模型。

一句话：模型就是“让前提都为真的一个世界”。

8.简答：严格地说，什么是“证明”？

参考答案：证明是一个有限公式序列，最后一项是要证明的公式，并且序列中每一项都必须是前提、公理，或由前面公式按允许的推理规则得到。命题演算中常见规则是 MP；谓词演算中还包括 Gen。

9.简答：K5 限制条件的意义是什么？举例说明。

参考答案：K5 为 ∀x(p→q)→(p→∀xq)，要求 x 不在 p 中自由出现。意义是：只有当前件 p 不依赖 x 时，才能把 p 放到全称量词外。

反例：∀x(P(x)→Q(x))→(P(x)→∀xQ(x)) 不合法。所有学生会写代码，不能推出“如果当前这个 x 是学生，则所有人都会写代码”。

10.直接证明：⊢ p→¬¬p。

简化证明：用演绎定理，只需证明 {p}⊢¬¬p。再用归谬思路：假设 ¬p，则与 p 矛盾，因此得 ¬¬p。

直接证明提示：若考试要求严格直接证明，需要用 L1、L2、L3、MP 展开；复习资料中的“第二双重否定律”或“p→¬¬p”可作为重点定理记忆。

11.直接证明：⊢(¬p→p)→(q→p)。

简化证明：由演绎定理，只需从 ¬p→p 和 q 推出 p。再由反证律/否定肯定律，¬p→p 可推出 p；因此 q→p 成立。

考试中若允许引用定理，可写：⊢(¬p→p)→p，再由加前件定理得到 p→(q→p)，组合推出结论。

12.事实分析：三个箱子有且只有一个有金子。三句话有且只有一句真：①第二个箱子没有金子；②第二个箱子有金子；③第一个箱子没有金子。问哪个箱子有金子？

答案：第一个箱子有金子。

设 A、B、C 分别表示第 1、2、3 个箱子有金子。三句话为 ¬B、B、¬A。前两句互为否定，必有且仅有一句真。题设总共只有一句真，所以第三句 ¬A 必须假，因此 A 真。

13.事实分析：甲说“不是苏州人，是上海人”；乙说“不是上海人，是苏州人”；丙说“不是上海人，也不是杭州人”。三人中一人全对，一人全错，一人对一半。判断王教授是哪里人。

解析：设 S=上海，Z=苏州，H=杭州。甲：¬Z∧S；乙：¬S∧Z；丙：¬S∧¬H。

若王教授是苏州人：甲全错，乙全对，丙一对一错，满足条件。

若王教授是上海人：甲全对，乙全错，丙一错一对，也满足条件。

结论：仅按这三种籍贯且题面如上，上海和苏州都满足。若原题要求唯一解，需要额外条件或题面可能漏字。考试中应列出两种可能并说明题面不足。

14.判断有效性：∃x₂∀x₁R(x₁,x₂)→∀x₁∃x₂R(x₁,x₂)。

答案：有效。

前件表示存在一个固定对象 b，使所有 x₁ 都满足 R(x₁,b)。于是对任意 x₁，都可取这个同一个 b 作为 ∃x₂ 的见证，所以右件成立。

15.判断并证明：⊢ ∀x₁R(x₁,x₂)→¬∃x₂∀x₁R(x₁,x₂) 是否正确？

答案：不正确。

给反模型即可。令论域为自然数，R(x,y) 解释为 x≥y，并令自由 x₂ 赋值为 0。则 ∀x₁R(x₁,x₂) 为真，因为所有自然数都 ≥0。

但 ∃x₂∀x₁R(x₁,x₂) 也为真，取 x₂=0 即可。所以右边的否定为假，整个蕴含为假。因此不是有效式，也不可证。

16.证明：⊢ ∃x₁∀x₂R(x₁,x₂)→∀x₂∃x₁R(x₁,x₂)。

证明思路：假设 ∃x₁∀x₂R(x₁,x₂)。由 EI 取见证 a，得 ∀x₂R(a,x₂)。任取 x₂，由 UI 得 R(a,x₂)。由 EG 得 ∃x₁R(x₁,x₂)。因为 x₂ 任意，由 UG 得 ∀x₂∃x₁R(x₁,x₂)。最后由演绎定理得原式。

17.前束范式：¬∃x∀y(P(x)∧Q(y))。

答案：∀x∃y(¬P(x)∨¬Q(y))

¬∃x∀y(P(x)∧Q(y)) ⇔ ∀x¬∀y(P(x)∧Q(y)) ⇔ ∀x∃y¬(P(x)∧Q(y)) ⇔ ∀x∃y(¬P(x)∨¬Q(y))

18.前束合取范式：(∀x₁)(P(x₁,x₂)∨(∀x₂)R(x₂,x₃))→(∀x₃)Q(x₁,x₃)。

答案思路：先改名，避免自由/约束变量冲突：

(∀u)(P(u,x₂)∨(∀v)R(v,x₃))→(∀w)Q(x₁,w)

消去蕴含并推否定：

¬(∀u(P(u,x₂)∨∀vR(v,x₃))) ∨ ∀wQ(x₁,w)

⇔ ∃u(¬P(u,x₂)∧∃v¬R(v,x₃)) ∨ ∀wQ(x₁,w)

提量词得一个前束形式：

∃u∃v∀w((¬P(u,x₂)∧¬R(v,x₃))∨Q(x₁,w))

化为合取矩阵：

∃u∃v∀w((¬P(u,x₂)∨Q(x₁,w))∧(¬R(v,x₃)∨Q(x₁,w)))
